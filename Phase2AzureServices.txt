Track H — Azure Services
27 topics · 8 parts · Frozen

Out of scope: The hundreds of Azure services outside this list, Azure network design in depth, Docker and Kubernetes fundamentals, pipeline authoring, application-level security techniques, and certification exam preparation.

This track covers the role, architecture, configuration, identity, tiers, limits, cost, reliability and trade-offs of the selected Azure services.

Depth: Master = hands-on; Reason = explain trade-offs; Aware = know it exists.

H12 Redis lifecycle note: Azure Managed Redis should be the forward-looking Azure Redis service to study. Do not teach Azure Cache for Redis as the default choice for a new Azure deployment. Understand its migration path and published retirement dates:
- Enterprise and Enterprise Flash: 31 March 2027.
- Basic, Standard and Premium: 30 September 2028.
Creation restrictions and migration requirements can vary by tier and customer status. Before choosing Azure Managed Redis for production, check feature maturity, SKU availability, regional availability, migration compatibility and current Microsoft guidance.

H15 identity lifecycle note: Azure AD B2C stopped being available for purchase by new customers on 1 May 2025. Existing customers can continue using it under Microsoft's published support commitments. B2C P2 has been retired; understand the implications for existing deployments. For new customer identity designs, evaluate Microsoft Entra External ID. Do not describe B2C as already shut down.

Learning rule: For Master topics, build a small .NET application on Azure—for example, a Container App using managed identity to access Key Vault and Azure SQL. Break it deliberately by removing a role assignment, expiring a secret or exceeding a quota. Investigate the resulting failure, then connect it to a production banking scenario. Set a budget alert and remove resources after experiments.
