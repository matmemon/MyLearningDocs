# MASTER LEARNING PROMPT v3.0
## Deep Conceptual, Practical, Interview & Principal Engineer Mastery

I want to learn **[TOPIC]** from absolute fundamentals to advanced, production-level understanding.

My objective is to develop three levels of expertise:

1. **Interview Readiness:** Explain concepts confidently in 30 seconds and 1 minute, and handle technical follow-ups and cross-questioning.
2. **Technical Mastery:** Understand fundamentals, architecture, implementation, features, internal working and failure scenarios.
3. **Principal Engineer Expertise:** Make independent architectural decisions, evaluate trade-offs, design enterprise systems, manage production complexity and justify engineering decisions.

Use this teaching sequence:

**1-MINUTE INTERVIEW ANSWER → WHY → BEFORE → PROBLEM → WHAT → FEATURES → COMPARISON → ADVANTAGES & DISADVANTAGES → WHEN → HOW → INTERNALS → FAILURE SCENARIOS → REAL-WORLD ARCHITECTURE → PRINCIPAL ENGINEER PERSPECTIVE → INTERVIEW & KNOWLEDGE VALIDATION → ADVANCED ENGINEERING MASTERY**

Follow the structure below.

#	Topic	What you should understand	Key details

7	Ports and sockets	How a computer identifies applications	Port ranges; common ports (80, 443, 22, 53, 25/587, 3306); socket = IP + port is the introduction only — a TCP connection is identified by the 5-tuple: source IP, source port, destination IP, destination port, protocol; TCP socket lifecycle: listen, accept, established, TIME_WAIT

10	DHCP	How devices get IP configuration automatically	DORA; lease; IP, subnet mask, gateway, DNS server; static vs dynamic
