Track I — Application Security
29 topics · 7 parts · Frozen

Out of scope: Network security configuration (firewalls, VPN, DDoS, TLS setup), security testing techniques, CI/CD pipeline hardening, SOC operations, physical and endpoint security, mobile and native app security, desktop app security, and network-layer DDoS/WAF rule authoring.

This track focuses on application and workload security: designing, coding, integrating and operating secure applications.

Depth: Master = hands-on; Reason = explain trade-offs; Aware = know it exists.

Learning rule: For Master topics, implement a secure .NET API or workflow, attack it deliberately, inspect the failure, fix it, and document the production control. For Reason topics, explain the trade-offs and control design. For Aware topics, understand the risk and know when to involve a specialist.
